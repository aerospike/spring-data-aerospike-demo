[[demo-reactive-query-methods]]
= Reactive Query Methods and Custom Queries Demo

This directory demonstrates current reactive Spring Data Aerospike repository query APIs. The active Spring Data
Aerospike version is configured in the root `pom.xml`; see the `Version Compatibility` section in the root README for
the current target stack.

== What This Demo Covers

- Reactive derived query methods and id-plus-bin criteria with `QueryParam`.
- Declared DSL queries with `@Query`.
- Programmatic custom queries with `Query` and `Qualifier`.
- DTO projection through `findUsingQuery(query, targetClass)`.
