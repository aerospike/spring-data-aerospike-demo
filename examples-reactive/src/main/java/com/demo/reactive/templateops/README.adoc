[[demo-reactive-template-operations]]
= Reactive Template Operations Demo

This directory demonstrates direct `ReactiveAerospikeTemplate` usage. The active Spring Data Aerospike version is
configured in the root `pom.xml`; see the `Version Compatibility` section in the root README for the current target
stack.

== What This Demo Covers

- Reactive query, count, exists, and projection template overloads.
- Batch id reads and deletes.
- Atomic bin mutations and partial updates.
