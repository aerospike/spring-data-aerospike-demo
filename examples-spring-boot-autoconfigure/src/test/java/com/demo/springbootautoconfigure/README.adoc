= Spring Boot Autoconfigure Tests

This directory contains tests for using generic Spring Boot auto-configuration with Spring Data Aerospike in a simple
Spring Boot application. The tests verify that the module-local auto-configuration creates the Aerospike client,
template, and repository beans from application properties, then exercise basic repository CRUD operations.

== Prerequisites

- JDK 17
