= Aerospike-backed Spring Cache

This guide points to a demo that uses Spring Cache annotations backed by `AerospikeCacheManager`. The active Spring Data
Aerospike version is configured in the root link:../pom.xml[`pom.xml`].

== What Is Covered

- Enabling Spring Cache with `@EnableCaching`.
- Creating an `AerospikeCacheManager` with a dedicated cache set.
- Reading through `@Cacheable`.
- Updating cached values with `@CachePut`.
- Evicting cached values with `@CacheEvict`.
