= Template Operations

This guide points to demo applications that use `AerospikeTemplate` and `ReactiveAerospikeTemplate` directly.
The active Spring Data Aerospike version is configured in the root link:../pom.xml[`pom.xml`].

== What Is Covered

- Query, `exists`, and `count` with `Query` and `Qualifier`.
- Target-class DTO projection from template query methods.
- Batch reads and deletes by id.
- Atomic numeric bin mutation with `add`.
- String bin mutation with `prepend` and `append`.
- Partial update with `update(document, fields)`.
- Blocking `persist(document, WritePolicy)` for operation-specific write policy overrides.

== Notes

The template query examples keep scans disabled and create the required secondary indexes on startup. This keeps the
demo aligned with the default Spring Data Aerospike behavior where scans are disabled unless explicitly enabled.
