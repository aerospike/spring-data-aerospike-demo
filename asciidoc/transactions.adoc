= Transactions

Spring Data Aerospike supports Spring transaction integration for Aerospike operations. The active Spring Data
Aerospike version is configured in the root link:../pom.xml[`pom.xml`].

== Requirements

Aerospike transactions require Aerospike Server `8.0+` and a transaction-enabled namespace. The transaction tests in
this repository check server support and skip with a clear reason when the local Docker-backed cluster does not support
transactions.

== What Is Covered

- Blocking transaction management with `AerospikeTransactionManager`, `@EnableTransactionManagement`, and
  `@Transactional`.
- Reactive transaction management with `AerospikeReactiveTransactionManager` and `TransactionalOperator`.
- Commit behavior for multiple repository/template writes.
- Rollback behavior for duplicate inserts.
