= Setup and Usage

This repository contains sample projects for demonstration of setting up and usage of Spring Data Aerospike.
It includes two modules: `examples` (imperative) and `examples-reactive` (reactive).

== Version Compatibility

This repository targets the Spring Data Aerospike version configured in the root link:pom.xml[`pom.xml`].
At the time of this update the demo targets Spring Data Aerospike `6.3.x`, Spring Boot `4.1.x`,
Aerospike Java Client `10.4.x`, Aerospike Reactor Client `10.5.x`, and Aerospike Server `6.1.x+`.

Transactions require Aerospike Server `8.0+` and a transaction-enabled namespace. Expression-index examples, if
enabled later, require Aerospike Server `8.1+`.

== Prerequisites

- JDK 17
- Docker installed and running (optional)
